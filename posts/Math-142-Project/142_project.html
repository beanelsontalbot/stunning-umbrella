Model 1: Competitive Species

We consider the following system that describes the dynamics of two competing species: \[ x' = x(1 - ax - y) \\ y' = y(b - x - y) + h \] where \(x\) and \(y\) represent the populations of the two species, and \(a\), \(b\), and \(h\) are parameters that affect the growth rates and interactions between the species. We assume that \(a, b > 0\). If \(h < 0\), then we are harvesting species \(y\) at a constant rate, whereas if \(h > 0\), we are introducing species \(y\) at a constant rate. The goal is to understand this system completely for all possible values of these parameters. As usual, we only consider the regime where \(x, y \geq 0\). If \(y(t) < 0\) for any \(t > 0\), then we consider this species to have become extinct.

1.

First we assume that \(h=0\) and investigate the different behaviors of the system for varying \(a\) and \(b\).

The horizontal nullclines are given by \(x=0\) and \(y=1-ax\). The vertical nullclines are given by \(y=0\) and \(y=b-x\). So we have four linear nullclines: the \(x\)-axis is a horizontal nullcline, the \(y\)-axis is a vertical nullcline, and the lines \(y=1-ax\) and \(y=b-x\) are also nullclines. The intersection points of these nullclines give us the equilibrium points (fixed points) of the system.

We see that varying \(a\) will change the slope of the nullcline \(y=1-ax\), while varying \(b\) will change the position of the nullcline \(y=b-x\). Therefore varying \(a\) and \(b\) changes the intersection points of the nullclines, and thus the equilibrium points (which occur at an intersection of a vertical nullcline and a horizontal nullcline). When \(a\) and \(b\) are chosen such that the stability or number of fixed point changes, this is called a bifurcation. In particular, we observe transcritical bifurcations (where a stable fixed point and an unstable fixed point collide and swap stability) at the critical values \(b_{c} = 1\) and \(a_{c} = 1/b\). Note that there is a special case when \(a = b = 1\), where the nullclines \(y=1-ax\) and \(y=b-x\) coincide completely, yielding a line of fixed points along \(y=1-x\).

Each equilibrium point is categorized by analyzing the associated Jacobian matrix at that point.

2.

Now we consider the case where \(h\neq0\). We will come to see that \(h\) more or less determines the curvature of the vertical nullclines – when \(h=0\) we saw that the vertical nullclines were lines, but when \(h\neq0\), the solution to \(y'=y(b-x-y)+h=0\) is no longer given by lines. Instead, it is a hyperbola.

Because of this different shape, when we move the curve between intersecting and not intersecting the horizontal nullclines, we go from having no intersection points to having two intersection points. This is called a saddle-node bifurcation because it creates one saddle fixed point and one unstable node.

function get_dots(){let dots;
    if (a != 1) {
        let y1 = (a*b-1+Math.sqrt((a*b-1)**2+4*a*h*(a-1)))/(2*(a-1));
        let y2 = (a*b-1-Math.sqrt((a*b-1)**2+4*a*h*(a-1)))/(2*(a-1));
        dots = [{X:0, Y:(b+Math.sqrt(b**2+4*h))/2}, {X:0, Y:(b-Math.sqrt(b**2+4*h))/2}, {X:(1-y1)/a, Y:y1}, {X:(1-y2)/a, Y:y2}]
    }
    else if (b != 1) {
        let y1 = h/(1-b);
        dots = [{X:0, Y:(b+Math.sqrt(b**2+4*h))/2}, {X:0, Y:(b-Math.sqrt(b**2+4*h))/2}, {X:1-y1, Y:y1}]
    }
    else {
        dots = [{X:0, Y:(b+Math.sqrt(b**2+4*h))/2}, {X:0, Y:(b-Math.sqrt(b**2+4*h))/2}]
    }
    return dots;
}

You may observe that if we fix \(h=-1\) and vary \(b\), it looks like we have one fixed point (a stable node) splitting into three fixed points, which at first glance looks like a pitchfork bifurcation. But a pitchfork bifurcation occurs in systems with perfect symmetry, unlike this one. What we are actually observing is a saddle-node bifurcation creating the two additional fixed points at the same time as a transcritical bifurcation swaps the stable node with the saddle. If we fix \(h\) closer to 0 and play with \(b\), we can see these bifurcations occurring separately.

Model 2: Susceptible-Infected-Recovered (SIR) Model

In this model, we put a twist on the SIR model of disease: instead of modeling the spread of a normal disease, we are trying to model a zombie apocalypse. This means that the infected population is more active in infecting the susceptible population than usual. We consider the system: \[ S' = -\beta S\sqrt{I} \\ I' = \beta S\sqrt{I} - \alpha I \]

  {value: 1, step: 0.001, label: "alpha"}
)
viewof beta = Inputs.range(
  [0, 3],
  {value: 1, step: 0.001, label: "beta"}
)
Code 
data4 = Array.from({length: 21}, (_, i) =>
  Array.from({length: 21}, (_, j) => {
    const x = (i / 5);
    const y = (j / 5);

    return {
      S: x,
      I: y,
      dS: -beta * x * Math.sqrt(y),
      dI: beta * x * Math.sqrt(y) - alpha * y
    };
  })
).flat()

This model is much simpler than the previous one, as there is only one fixed point: the origin. No matter how we adjust \(\alpha\) and \(\beta\), the origin is always a stable node. Changing \(\alpha\) and \(\beta\) changes the shape of the vertical nullcline, which, in the context of our model, represents the susceptible/infected population ratio at which both populations begin to decline until reaching zero.
